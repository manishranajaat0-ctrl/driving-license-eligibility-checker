# DriveCheck — Driving License Eligibility Portal

A web development capstone project that evaluates whether an applicant is eligible for a driving license based on two mandatory conditions:
- **Age >= 18**
- **Practical Driving Test = Passed**

## Live Demo
[Open Live Project](<tumhara-live-link>)

## Features
- Real-time DOB-to-age calculation and validation
- Transparent Boolean logic breakdown (`Age >= 18 && Test Passed`)
- Digital Provisional Driving License preview card for eligible applicants
- Persistent verification audit log using browser `localStorage` with status filters
- Light & Dark mode support
