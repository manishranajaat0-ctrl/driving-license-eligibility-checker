TRUE FALSE INELIGIBLE Driving test failed or not taken

  • Progressive Disclosure: Driving test options are shown only when age is 18 or above; underage inputs immediately surface an ineligibility notice without asking for test results.
  • Exact Birthday Boundary: When Date of Birth is used, exact years, months, and days are computed against the local calendar date so someone turning 18 today qualifies immediately.
Capstone Architecture & Deliverables
Client-side web engineering overview
Architecture
  • Frontend Stack: Semantic HTML5, responsive CSS3 custom properties, and vanilla ES6+ JavaScript with zero external runtime dependencies.
  • Input Validation & Guardrails: Prevents blank names, out-of-range ages, future dates of birth, and missing required selections.
  • Persistence & Reporting: Persists every verification event in localStorage with live KPI metrics, search/filter controls, CSV export, printable certificate view, and plain-text summary download.
